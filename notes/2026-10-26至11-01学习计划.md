## ResNet 阶段当前结果

代码目录：`week6_RestNet/CIFAR_10_resnet/`

- 自定义 ResNet18：验证准确率约 83%～84%，训练准确率接近 98%，存在明显过拟合。
- 自定义 ResNet 的一次测试集结果：约 82.95%。
- 只训练分类头：历史结果约 53.12%。
- 解冻 `layer4 + fc`：历史结果约 75.88%，训练集很快接近 100%。
- 全量微调：历史结果约 89.40%，目前迁移实验中效果最好。

这些结果只能作为当前实验记录，不能直接得出“某种模型一定更好”的结论，因为数据划分、输入预处理、归一化和冻结范围并不完全相同。

## 需要优先复习和修正的内容

1. **训练集、验证集、测试集的职责**：训练参数，验证选模型和调参，测试只做最终报告。
2. **参数冻结与 BatchNorm 状态**：`requires_grad=False` 不等于 BatchNorm 运行统计量不变化；理解 `train()` 与 `eval()` 的区别。
3. **迁移学习可复现性**：当前 `transfer_learninf.py` 中 A/B 方案部分优化器代码被多行字符串注释，实际运行代码是全量微调。需要把 A、B、全量微调整理成真正可运行的模式。
4. **实验控制变量**：记录模式、输入处理、数据划分、随机种子、学习率、冻结范围、可训练参数量和训练时间。
5. **评估数据顺序**：验证集和测试集 DataLoader 使用 `shuffle=False`，便于复现和错误样本分析。

## 本周主题

**迁移学习代码收尾 → Attention → Transformer Block → Patch Embedding → Tiny ViT**

本周不追求刷 CIFAR-10 准确率，重点是理解视觉 Transformer 的数据流和训练工程。

## 每日计划（约 20 小时）

### 周一：整理迁移学习代码（3 小时）

- 把 A（只训练分类头）、B（解冻 `layer4 + fc`）、C（全量微调）整理成可运行模式。
- 根据模式设置 `requires_grad` 和优化器参数组。
- 打印并保存可训练参数数量、学习率、冻结范围和模式名称。
- 每种模式先运行 1～2 个 epoch 做冒烟测试。

验收：确认实际更新的参数与设计一致，配置能够复现实验。

### 周二：BatchNorm 与冻结行为（3 小时）

用小实验检查：

- 冻结参数后梯度是否为 `None`；
- `model.train()` 时 BatchNorm 的 `running_mean` 是否变化；
- `model.eval()` 后是否停止更新；
- 分类头和骨干网络如何分别设置训练状态。

验收：用自己的话解释“冻结参数”和“冻结模型状态”的区别。

### 周三：手写单头 Self-Attention（3 小时）

实现：

```text
X → Q、K、V → QKᵀ / sqrt(d) → softmax → 与 V 相乘
```

必须检查并写出张量形状：

```text
X: [batch, tokens, dim]
Q/K/V: [batch, tokens, head_dim]
attention: [batch, tokens, tokens]
output: [batch, tokens, head_dim]
```

### 周四：Multi-Head Attention 和 Transformer Block（3 小时）

- 实现多头拆分与合并；
- 加入 LayerNorm、FFN 和残差连接；
- 理解：

```text
Transformer Block
= Attention + Residual + LayerNorm
  + FFN + Residual + LayerNorm
```

验收：随机输入可以完成前向和反向传播，所有输出形状正确。

### 周五：Patch Embedding（3 小时）

使用 CIFAR-10 图片做实验：

- 图片尺寸：`32 × 32`；
- patch size：`4 × 4`；
- token 数量：64；
- embedding dim：128 或 192。

完成图像切 patch、展平、线性映射和位置编码，并记录每一步张量形状。

### 周六：Tiny ViT（3 小时）

- 用 Patch Embedding、位置编码、Transformer Block 拼出小型 ViT；
- 在 CIFAR-10 上先训练 3～5 个 epoch；
- 理解 `CLS token`、分类头和位置编码的作用；
- 观察是否出现过拟合。

验收：模型能完成训练、验证和 checkpoint 保存，不要求超过 ResNet 准确率。
