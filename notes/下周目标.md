## 下周目标

完成以下五件事：

1. 配置好 Python、PyTorch、Git 和开发环境；
2. 能独立写出几个基础 Python 程序；
3. 复习数组、哈希表、排序等基础数据结构；
4. 跑通导师项目或至少完成代码结构分析；
5. 建立学习记录和 Git 提交习惯。

第一周不追求做出复杂项目，重点是重新找回“能写、能运行、能排错”的感觉。

## 每日计划

### 周一：环境配置和现状确认

学习和操作：

- 安装或确认 Python；

- 安装 VS Code 或 PyCharm；

- 配置虚拟环境；

  ```python
  python -m venv ye1
  ###激活
  .\ye1\Scripts\Activate.ps1
  pip install torch numpy pandas
  ```

- 安装 NumPy、Pandas、PyTorch；

  学习到了：安装Numpy pip install Numpy

  安装PyTorch要注意版本

  一切安装好之后可以保存配置文件requirements.txt(     pip freeze > requirements.txt) 

- 安装 Git；

- 注册或整理 GitHub/Gitee；

- 建立一个个人学习仓库。

建议建立这样的目录：

```text
ai-learning/
├── python/
├── pytorch/
├── algorithms/
├── projects/
└── notes/
```

当天结束时，完成一个 `hello.py`，并成功提交到 Git。

如果导师项目需要 GPU，先确认：

- 是否有服务器；
- 如何登录；
- CUDA 和 PyTorch 版本；
- 项目依赖如何安装；
- 是否有 README 或运行说明。

### 周二：Python 基础恢复

复习：

- 变量和数据类型；
- 字符串；
- 列表、元组、字典、集合；
- 条件和循环；
- 函数；
- 文件读写；
- 异常处理。

练习：

1. 统计一段文本中每个词出现的次数；
2. 读取一个 CSV 文件并统计每列信息；
3. 编写一个简单的日志分析程序；
4. 把代码拆成多个函数。

要求：不要只看视频，每学一个知识点都写代码。

### 周三：Python 面向对象和数据处理

学习：

- 类和对象；
- 模块和包；
- `pip`；
- 虚拟环境；
- JSON；
- CSV；
- NumPy 数组；
- Pandas DataFrame。

练习：

- 读取一个 CSV；
- 删除空值；
- 统计类别分布；
- 绘制一个柱状图；
- 保存处理后的数据。

这一天的重点是理解：**机器学习项目本质上大量时间都在处理数据。**

### 周四：数据结构和算法基础

复习：

- 数组；
- 链表；
- 栈；
- 队列；
- 哈希表；
- 排序；
- 二分查找。

完成 4～5 道简单题即可，建议优先：

- 两数之和；
- 有效括号；
- 合并两个有序数组；
- 二分查找；
- 反转链表。

不要一开始刷困难题。你现在需要的是恢复思维和代码熟练度。

### 周五：PyTorch 入门

学习：

- Tensor；
- 张量的形状；
- CPU 和 GPU；
- 自动求导；
- `nn.Module`；
- 优化器；
- 损失函数。

练习：

- 创建并操作不同维度的 Tensor；
- 完成一次矩阵乘法；
- 用 PyTorch 拟合简单线性函数；
- 保存和加载一个模型。

你需要真正理解：

- 输入是什么；
- 输出是什么；
- 损失如何计算；
- 参数如何更新。

### 周六：分析导师项目

这一天不要急着改代码，先做项目地图。

回答这些问题：

- 项目解决什么问题？
- 输入数据是什么？
- 数据放在哪里？
- 数据如何预处理？
- 模型是哪一个？
- 训练入口文件在哪里？
- 推理入口文件在哪里？
- 损失函数是什么？
- 评价指标是什么？
- 运行一次需要什么命令？
- 你目前负责哪部分？

如果项目很大，先找以下文件：

- `README`
- `requirements.txt`
- `environment.yml`
- `train.py`
- `test.py`
- `inference.py`
- `dataset`
- `model`
- `config`

把项目结构画成简单文字记录，不需要马上完全理解。

### 周日：复盘和小测

完成一个小练习：

然后写一份周总结，回答：

## 下周每天的时间分配

每天可以按这个节奏：

- 1 小时：看教程或复习概念；
- 2 小时：跟着写代码；
- 1 小时：完成独立练习；
- 30 分钟：整理笔记和 Git 提交。

如果某天只有 2～3 小时，优先保留“独立写代码”的时间，少看视频。
